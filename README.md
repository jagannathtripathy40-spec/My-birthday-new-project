## 🌟 About the Project

This is a special birthday surprise website dedicated to **Jagannath Tripathy**.

Instead of sending an ordinary birthday message, I created an interactive website filled with funny jokes, birthday animations, playful surprises and a special birthday celebration.

Because friends deserve something more than just a simple "Happy Birthday"! 😂

## ✨ Features

- 🎁 Interactive welcome screen.
- 🎵 Background birthday music.
- 🎊 Colourful confetti animations.
- 😂 Funny birthday roast generator.
- 🎂 Interactive birthday cake with candle-blowing animation.
- 🎁 Mystery gift surprise.
- 🥳 Special birthday finale.
- 📱 Fully responsive mobile-friendly design.
- 🎨 Colourful and playful birthday-themed interface.

## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/mohitkpani/jagannath-birthday.git
```

**2. Navigate to the project folder**

```bash
cd jagannath-birthday
```

**3. Open the website**

Open `index.html` in your favourite browser.

That's it! Your birthday surprise is ready! 🎉
